# 3.NAVO — Plan. Build. Grow.

Modern, responsive 3D website source for **3.NAVO** featuring our signature **Plan • Build • Grow** framework.

## Open and run

1. Open this project folder in your editor.
2. The local server is already running on:
   **http://localhost:8000**
3. Or manually start a local server anytime:
   - Windows: `python -m http.server 8000`
   - Node: `npm run dev`
